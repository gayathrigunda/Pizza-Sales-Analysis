# 🍕 Pizza Sales Dashboard | Data Analysis Project 

## About 
This project showcases an interactive Pizza Sales Dashboard designed to analyze sales performance, customer ordering patterns, and product-level insights. It demonstrates practical data analysis and visualisation skills using real-world sales data. 

## 🎯 Key Objectives 
- Analyze total revenue, orders, and pizzas sold
- Identify busiet days and peak sales periods
- Compare sales by pizza category and size
- Highlight best and worst selling pizzas

## 📈 Key Metrics 
- Total Revenue
- Average Order Value
- Total Orders & Pizzas Sold
- Average Pizzas per Order 

## 📊 Dashboard Highlights 
- Daily and monthly order trends 
- Sales distribution by pizza category and size
- Best & Worst sellers by revenue, quantity, and orders
- Interactive filters for date range and pizza category

## 🛠 Tools Used 
- Power BI
- Data Cleaning & Transformation
- Data Visualization & Business Analytics
